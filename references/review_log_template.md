# 审阅记录模板

审阅记录是整个审阅过程中唯一的事实来源：执行修改的会话只看这份文件。所以它要写得让一个没有参与审阅的人也能照着改。

## 文件结构

```markdown
# 逐节审阅记录（<开始日期> 起）

这份文档汇总作者逐节审阅时提出的修改。**审阅期间不改稿件**，全部审完后统一修改、重新生成，并更新存档。

状态说明：

- **已定**：作者已确认要改；
- **方向已定**：作者确认了修改方向，具体措辞改完后再审；
- **待定**：只是建议，作者还没有表态；
- **不改**：作者决定保持原样；
- **已并入 Xn / 不再需要**：被后来的决定取代。

审阅进度：

- [ ] 题目、摘要、关键词
- [ ] 1. Introduction
- [ ] 2. Methods
- [ ] 3. Results
- [ ] 4. Discussion
- [ ] 5. Conclusions
- [ ] 补充材料

---

## 一、跨章节修改

**作者意见（<日期>）**：<作者原意>

**依据**：<数据表、原文引文、计算结果；注明来源文件>

**写作时必须守住的几点**：<例如不能写成什么样>

**涉及位置**

| 位置 | 现在 | 改为 |
|---|---|---|

|---|---|---|---|

（同上表格，编号 I1, I2 …）

---

## 三、引用相关事项（R）

| 编号 | 位置 | 建议 | 状态 |
|---|---|---|---|

---

## 四、审阅完成后的统一修改流程（备忘）

1. 备份源文件、生成稿、图件和参考文献。
2. 按"已定"和"方向已定"的条目修改源文件。
3. 新增文献先核对元数据，再写入并重新编号。
4. 重新生成全部文件；重跑数值核对，确认没有数值被意外改动。
5. "方向已定"的条目，把改前改后对照发给作者再审。
6. 更新修订记录和存档。
```

## 示例条目（虚构，仅示范写法）

**表格条目**

| 编号 | 位置 | 建议 | 状态 |
|---|---|---|---|
| R3 | §1 第 2 段 | "has been shown to reduce X over time [8, 9]"：[8] 只做了横截面比较，没有时间维度，改为 "is associated with lower X [8, 9]" | 已定 |
| A2 | 摘要第 2 句 | "eligible" 没有定义，补写入选标准（约 +10 词，摘要已到字数上限，需要在 A5 处压缩） | 已定 |
| P7 | 补充材料 S4 整节 | 探索性分析，正文没有用到它的结果，对结论没有贡献；整节删去，正文中两处相关句子同步删去，只在此处使用的一条参考文献随之删除并重新编号 | 已定（作者原则） |

**取代关系的写法**

> X2 吸收并取代 X1 的"涉及位置"表：X1 关于数据依据和"三点注意"的内容继续有效，具体改法以本节为准。

**有依据的草稿**

> **依据（逐年数据）**：结果变量单年降幅最大的一年在处理前一年（−0.012 → −0.031；n = 500）。来源：`data/yearly_summary.csv`（筛选后样本）。
